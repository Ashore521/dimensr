# DimenSR 真实数据可行性验证

实验日期：2026-10-17。当前实现能够在三个公开实测数据集上完成训练、生成表达式和独立测试；船体阻力任务的预测效果较好，翼型噪声与混凝土任务仍有明显精度差距。**这支持初步可用性，尚不支持“优于已有算法”或“发现了真实物理定律”的结论。** 混凝土完整模型还出现了一次负强度预测，表明量纲合法不等于物理可接受。

本次共完成 42 次运行：完整 DimenSR 9 次、关闭量纲约束 6 次、三个预测基线共 27 次。没有失败的拟合，也没有测试点上的非有限预测。配置在看到本轮测试分数前固定，未根据测试结果修改算法、预算或筛选种子。协议于 10:53:25 UTC 保存，见 [可核验记录](../results/real_data/protocol.json)；完整方法见 [实验协议](REAL_DATA_PROTOCOL.md)。

## 独立测试结果

下表是三个种子的 **R² 均值 ± 样本标准差**，越大越好。所有方法使用相同划分；验证集选择最终模型或基线超参数，测试标签不参与拟合和选择。Ridge 的 alpha 在五个固定值中选取，随机森林固定 200 棵树，在三个叶节点最小样本数中选取。

| 方法 | 翼型噪声 | 混凝土强度 | 船体阻力 |
| --- | ---: | ---: | ---: |
| 完整 DimenSR | **0.424 ± 0.153** | **0.496 ± 0.037** | **0.990 ± 0.006** |
| DimenSR 关闭量纲约束 | 0.394 ± 0.114 | 0.425 ± 0.094 | 未重复运行：原数据已全部无量纲化 |
| 训练均值预测 | -0.004 ± 0.005 | -0.049 ± 0.046 | -0.0002 ± 0.0002 |
| Ridge | 0.493 ± 0.050 | 0.581 ± 0.058 | 0.659 ± 0.002 |
| 随机森林 | 0.812 ± 0.060 | 0.856 ± 0.015 | 0.995 ± 0.002 |

每个种子的完整模型测试 R²：翼型为 0.4230、0.2712、0.5775；混凝土为 0.4975、0.4577、0.5319；船体为 0.9945、0.9828、0.9927。没有只展示最好种子。三个划分的测试样本可能重叠，且种子同时影响划分与搜索，标准差仅描述本轮波动，不是置信区间。

所有完整模型都优于训练均值；船体的简短公式在未见过的船体组上仍有较高预测精度。翼型与混凝土的平均效果低于 Ridge，三个任务平均效果均低于随机森林，因此目前不能主张精度优势。量纲开启后两个物理任务的平均 R² 有所提高，但只有三个种子、实际计算量不同，不能据此认定显著增益。

## GP 中的量纲检查与物理边界

运行时对每棵首次进入评价器的树重新校验所有算子、叶节点和目标量纲，覆盖神经网络种子和 GP 后代，也包含后来因数值定义域不合法而被拒绝的树。重复缓存树在首次出现时已检查；此检查不改变搜索结果。

| 完整模型任务 | 三个种子的唯一评价树数 | 量纲违规 |
| --- | ---: | ---: |
| 翼型噪声 | 1538 + 1517 + 1527 = 4582 | 0 |
| 混凝土 | 1303 + 1388 + 1311 = 4002 | 0 |
| 船体阻力 | 1729 + 1678 + 1648 = 5055 | 0 |
| 合计 | **13639** | **0** |

其中 **8584 棵来自具有非平凡物理量纲的前两个任务**。船体字段和目标全为无量纲量，不能用它证明量纲模块带来收益。关闭量纲的版本只检查全零类型体系，不能称作物理量纲验证。

量纲处理需要正确理解：

- 翼型输出 dB 作为无量纲对数量处理，不能标成压力 Pa；量纲规则未完整表达分贝运算的语义。
- 混凝土先将 day 转为 s、MPa 转为 Pa。训练集得到的数值缩放因子按无量纲乘数使用，不做中心化，缩放变量保留物理量纲；预测按照保存因子还原到原始单位。
- 未知系数显式允许无量纲、目标量纲，以及“目标量纲减特征量纲”。因此常数数字可能带有单位，真实单位保存在原始树中。合法量纲不保证系数有物理依据，也不保证正性、单调性或区间外行为。

事后检查测试预测的物理范围发现：**混凝土完整模型 seed 1 在一个测试样本上预测 -31.205 MPa**；关闭量纲的 seed 0 有四个负值。其余完整模型的混凝土测试预测未出现负值，详见 [物理范围诊断](../results/real_data/physical_checks.json)。这些点全部保留在误差计算中，没有裁剪为零，也没有删去。该诊断未用于调参，它揭示了下一步需要研究的正性约束与域安全问题；不能把“数值有限、量纲一致”当作“所有预测都物理合理”。

## 实际表达式示例

以下均取预先编号的 **seed 0 完整模型**，还原到源数据的数值单位。系数仅为阅读做了舍入；实际预测应使用保存的原始树。

混凝土模型可写为：

\[
\widehat S=aP+bC\left(1-\frac{\tau}{t}\right),\quad
a\approx1.00722\;\mathrm{MPa\,m^3/kg},\quad
b\approx0.121003\;\mathrm{MPa\,m^3/kg},\quad
\tau\approx1.73856\;\mathrm{day}.
\]

C 是水泥用量、P 是减水剂用量，均以 kg/m³ 输入；t 是龄期（day），输出为 MPa。各项量纲一致，但它只使用部分配方变量，测试 R² 为 0.4975，**不是充分的混凝土强度定律**；例如 t=0 处有奇点，未验证的早龄期还可能产生不合理预测。

船体模型的近似展示式为：

\[
\widehat R=\frac{16357.759\,F_n^4\exp(6.5648795F_n)}
{(0.24459682\,B/T+16.483440\,C_p+5.7008649)^2}.
\]

F_n 为 Froude 数，B/T 为宽吃水比，C_p 为棱形系数，全部无量纲；R 保持数据发布时的阻力系数数值尺度。此模型测试 R² 为 0.9945。测试是新船体几何组，Froude 数范围与训练范围重叠，不能据此声称速度区间外的外推能力。

## 复核与复现

本机环境：Windows 11，Python 3.12.10，NumPy 2.5.4，SciPy 1.18.1，scikit-learn 1.9.1，PyTorch 2.14.1+cpu；Torch 与数值库线程限制为 1。42 次运行记录的时间累计约 286 秒，不含下载与准备。这是固定的小规模预算，并非充分搜索。完整模型每次实际评价 1303–1729 棵唯一树，未用满 4000 次上限；固定轮数、重复树和缓存也会限制实际消耗。

**37 项软件测试通过。** 独立复核脚本从原始数据、保存划分和 15 个 JSON 模型重新计算三份集合的指标；同时由保存的测试预测重算全部 42 次测试分数，全部一致。复核没有重新训练符号模型。原始树推理与化简展示公式分开处理，避免符号消项掩盖定义域问题。

在仓库根目录复现实验：

```bash
python -m pip install -e ".[experiments]"
python -m dimensr.real_data --output outputs/my_real_data
python examples/verify_real_data.py --output outputs/my_real_data
python -m pytest -q
```

只复核已发布结果，先下载原始缓存，再运行：

```bash
python -m dimensr.real_data --prepare-only --output outputs/data_download
python examples/verify_real_data.py --output results/real_data
```
