# 0.3 边界合法性与复杂公式搜索实测

2026-10-23。0.3 在本轮 18 个任务—种子组合中严格恢复 12 个，0.2 恢复 2 个；预先规定的有限检查集上，最终模型出现非法运算的运行从 5 个降到 0 个。此次更新提高了复合三角公式、带量纲公共分母和根式公式的发现能力。双对数与指数乘积任务仍未恢复；外推区间内还发现了未被有限随机点命中的极点，因此“0 次检查失败”不能解释为全域合法。

## 改动与实验口径

0.3 对原始树的每个中间运算检查有限性，加入训练范围端点、角点与域内零点，并允许用户声明合法矩形范围或无标签输入点。候选系数试算不满足检查时被拒绝。比如 `1/(1/x)` 在零点即使外层结果看似有限，也判为非法。对数、平方根沿用真实定义；GP 和新初始化均遵守原有量纲文法。

复杂结构初始化先建立有限的复合函数库，再用训练数据拟合稀疏加法结构和公共分母结构。全部提议仍经过普通评价器和定义域检查。RNN–GP、NSGA-II、SD 和局部 Rademacher 项保留。

[执行前方案](BOUNDARY_SEARCH_PROTOCOL.zh-CN.md)规定 6 个公式 × 3 个种子 × 3 个版本，共 54 次无噪声拟合。旧版源码固定于 `a555f11b0e635c251d8eac2a0001e3c6452df9b1`；新版源码和数据在首个拟合前冻结。训练/验证行数为 192/96，IID 与外推各 768 行，另设精确边界和独立应力检查。详细输入规则、环境和哈希见 [protocol.json](../results/boundary_search_v3/protocol.json)。

严格恢复要求最终原始树在四组评分数据上均满足 `NRMSE < 1e-6`，且没有非法中间运算。这是数值恢复，不是符号恒等证明。新版两组均获得相同的无标签合法边界点；旧版使用原始 API。全部拟合结束后才读取测试标签。四个旧任务是已知困难案例的回归测试，两个新增任务也由开发者选择，不能作为未知公式总体成功率的估计。

## 结果

54/54 次拟合成功，无崩溃或超时。每列均含 18 次运行。

| 指标 | 旧版 0.2 | 仅加强边界检查 | 完整 0.3 |
|---|---:|---:|---:|
| 最终模型严格数值恢复 | 2/18 | 1/18 | **12/18** |
| 任一保存候选严格数值恢复 | 2/18 | 1/18 | **12/18** |
| IID R² > 0.999 | 15/18 | 15/18 | **18/18** |
| 规定检查集上最终模型非法运行数 | 5/18 | 0/18 | **0/18** |
| 保存 Pareto 候选中的非法模型数 | 57/320 | 3/336 | **0/231** |
| 保存树量纲违规数 | 0 | 0 | **0** |
| 单次拟合中位耗时（秒） | 33.17 | 39.46 | 40.42 |
| 单次唯一树评价数中位数 | 1349.5 | 1344.5 | 1443.0 |

候选非法模型数是在四组评分集上统计；“仅加强边界检查”的 3 个非法候选均未被选为最终模型。最终与任一保存候选的恢复数相同，本轮没有观察到“正确公式已保存在 Pareto 集中，却被最终优选丢失”的情况。这一结论仅覆盖保存候选。

| 公式 | 旧版恢复 | 仅加强边界 | 完整新版恢复 |
|---|---:|---:|---:|
| `sin(x²)cos(x)−1` | 1/3 | 0/3 | **3/3** |
| `log(1+x)+log(1+x²)` | 0/3 | 0/3 | 0/3 |
| `(m1*r1+m2*r2)/(m1+m2)` | 1/3 | 0/3 | **3/3** |
| `m/sqrt(1−v²/c²)` | 0/3 | 0/3 | **3/3** |
| `exp(x)cos(y)+0.2xy`（探索） | 0/3 | 1/3 | 0/3 |
| `1.7x/(0.8+x)`（探索） | 0/3 | 0/3 | **3/3** |

新版的根式表达式直接使用 `v²/c²`，无需通过 `1/v` 构造，所以在允许的 `v=0` 边界保持合法。质心模型在单个质量为零时可求值；总质量为零的点从一开始就被物理输入合同排除。

## 未解决的问题

对训练数据的事后诊断未改动冻结算法：Nguyen-7 的 `log(1+x)` 已在特征库中，但未进入相关性排名前 48 的候选；指数乘积任务的 `exp(x)*cos(y)` 未进入已满的 512 个特征库，`xy` 也被相关性预筛截掉。诊断记录见 [posthoc_search_diagnostics.json](../results/boundary_search_v3/posthoc_search_diagnostics.json)，直接检查的是种子 41，不能把该机制的逐例验证扩展为全部种子都已检查。

两组失败任务的 IID R² 仍很高，外推却可能很差。指数乘积任务种子 41 的外推 NRMSE 为约 459.52；其公式含分母 `x−1.9144014067760036`。在精确输入 `(x,y)=(1.9144014067760036,1.5)` 上复核，原始树非法，`predict` 正确报错。该点位于外推区域 `[1,2]²`，位于声明输入域 `[0,1]²` 之外；注册的有限采样没有恰好命中极点。该[事后反例](../results/boundary_search_v3/posthoc_domain_counterexample.json)保留为独立证据，不改写原评分。

因此本轮完成的是“已声明有限边界检查 + 逐节点严格求值”，连续域证明仍未实现。下一轮可针对原始分母/对数/根号建立区间分析和自适应危险点检查；复杂搜索可改进数值重复特征去重、库容量分配和残差导向筛选。这些需要新实验目录，不得用本轮测试集反复调参后沿用原验证结论。

## 计算成本、复核与环境

三个版本均限制最多 2048 棵唯一评价树、21 个节点、7 层深度。完整新版额外进行了 218–548 次特征预览和 6800–18964 个线性子问题；特征库最多保留 512 个，失败预览也计入求值次数。新增工作不计入普通评价器唯一树数。这不是等计算量比较；并行运行时的耗时仅作诊断。

独立复核加载 54 个模型，检查 941 棵保存树（包括每个最佳模型，可能与 Pareto 集重复），验证原始运算、量纲、预算、训练/验证指标及保存后预测。新版两组的 603 棵保存树均通过其声明探针复核。固定选择协议中的首个完整新版任务 `Nguyen-5_s41_v03` 重放，除 `elapsed_seconds` 外所有模型字段完全相同，四组预测数组逐项相同。该重复只覆盖一个任务，不代表跨平台位级复现。

本地测试 **79 项通过**，源码包和 wheel 构建成功；wheel 安装到独立目录后，CLI 读取域 CSV/范围 JSON、保存加载及零点预测通过。首次 wheel 安装遇到沙箱临时目录权限错误，改用项目临时目录后成功。依赖检查无冲突，本轮不需要新增第三方依赖。

运行环境：Windows 11、Python 3.12.10、NumPy 2.5.4、SciPy 1.18.1、PyTorch 2.14.1+cpu、SymPy 1.14.0、scikit-learn 1.9.1。后续按用户授权在项目隔离环境中自动安装所需环境和依赖，并记录版本。
