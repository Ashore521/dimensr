# DimenSR 实现与验收

输入为项目提供的设计方案、五篇论文及 PhySO、DSO 仓库。交付为可安装的独立 Python 仓库。

1. 实现不可变表达式树、精确有理数量纲与可完成性约束语法；验证错误量纲及非法数值域。
2. 实现 GRU 表达式策略、风险寻求策略梯度和 GP 精英监督回流；验证梯度更新与固定种子重现。
3. 实现同量纲交叉/变异、训练集常数优化、NSGA-II 和规模多样性；验证 Pareto 支配、边界保留和变异闭包。
4. 实现有限局部函数族的 Monte Carlo Rademacher 估计、候选池和验证集最终选择；验证数据隔离。
5. 完成 API、CSV CLI、JSON 模型导出、示例、消融基准、使用说明、来源与许可证、CI；运行测试并保存实测结果。
6. 构建发布包，检查仓库内容，完成可用权限范围内的 GitHub 发布。

不把文献 PDF、未公开设计原稿或本地环境提交到发布仓库。算法效果和新颖性分别需要实验和更广泛的文献评估；首版报告实际完成的验证。
