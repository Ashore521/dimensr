# 0.4 区间筛查与互补特征搜索验证方案

2026-10-23，拟合前确定。继承 ARS experiment-agent 的执行/复核流程。

问题：0.3 的有限点检查可能漏掉极点；初始特征容量和单项排名可能丢弃互补项。0.4 加入有界区间细分、训练数值特征去重、乘积空间预留、条件残差筛选与两项联合预筛。

固定比较三组：提交 `cb520c96daf63922b31009e8382ea3a436d731cf` 的 0.3、新搜索且关闭区间检查的 `search_only`、完整 0.4。沿用六个已知任务，使用新种子 71/82/93 和独立生成数据，共 54 次拟合。它们是回归测试，不是新的盲测任务。每组的输入域、训练/验证数据、算子、树预算和最终选择规则相同。

此次所有组都获得覆盖训练及外推范围的声明矩形域和无标签边界点。质心矩形使用正质量 `[0.1,7]²` 与位置 `[0,7]²`，质量为零且总质量为正的边界另用有限点检查；不将耦合域宣称为一个完整已验证矩形。相对论式采用 `m∈[0,7], v∈[0,2.8], c∈[3,14]`；其他任务矩形取原训练域和外推域的包围盒。与 0.3 旧实验的信息合同不同，只在本轮三组之间比较。

配置：192 行训练、96 行验证，768 行 IID、768 行外推，另有精确边界和 512 个初始应力点（仅按已声明输入约束过滤）。无噪声。种群 48、8 个外循环、每轮 2 代 GP、6 代 NSGA-II、2048 棵唯一评价树、21 节点、7 层。最多 3 个单线程进程并行，每次硬超时 240 秒，失败保留，不选择性重跑。输入文件与源码在首个拟合前记录哈希，全部拟合结束后才进行测试评分。

主指标：最终原始树在 IID、外推、边界、应力四组上均 `NRMSE<1e-6`，中间运算无非法值。次指标：任一保存候选恢复、IID R²>0.999、有限检查集上的非法运行数、量纲、耗时和额外计算量。额外统计特征预览、线性子问题、两项预筛、残差投影、区间处理数量。三组的唯一树上限相同，但不构成等计算量对照。

完整新版的每个保存候选必须在声明矩形上得到 `enclosed`。`invalid` 只表示已找到实际反例；`unresolved` 包括区间依赖或预算耗尽，两者都不接受。实现以浮点区间包围和最多 32 个子盒筛查，数学库的超越函数并非形式化验证实现，`enclosed` 不应标注为数学定理或任意域的全局安全证明。仅显式合法点模式不会偷偷生成矩形。

复核包括：保存模型重载、独立逐节点求值、训练/验证指标、所有候选单位和容量、源/数据/结果哈希、完整新版候选区间审计。预先选择首个完整新版任务 `Nguyen-5_s71_v04` 作一次精确重放，仅忽略耗时字段。另保留对旧版外推极点反例的区间审计，检查新接口能否明确拒绝无安全结论的域。
