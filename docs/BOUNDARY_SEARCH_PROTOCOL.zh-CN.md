# 0.3 边界合法性与复杂结构搜索对比方案

日期：2026-10-22。状态：执行前确定；具体冻结时间、源码哈希、数据哈希、环境和配置见 `results/boundary_search_v3/protocol.json`。

本轮比较 0.2.0 固定源码、关闭结构初始化的新版（boundary_only）、完整 0.3.0。四个已诊断公式用于回归验收：Nguyen-5、Nguyen-7、Feynman-I.18.4、Feynman-I.10.7。另设 `exp(x)*cos(y)+0.2*x*y` 和 `1.7*x/(0.8+x)` 两个探索性迁移任务。公式已由开发者知晓，不能称为盲测任务。所有样本和随机种子与上一轮不同。

1. 每个任务使用种子 41、52、63，各运行三个版本，共 54 次拟合；无噪声。训练 192 行、验证 96 行、IID 测试和外推各 768 行；另有 512 个初始应力检查点，按预先规定的物理输入约束过滤，以及精确边界点。应力检查在坐标端点、零点附近和随机输入组合上进行。
2. 各版本使用相同训练/验证/测试数据、算子集、21 节点与 7 层限制；唯一树评价上限 2048，种群 48，8 个外循环，每轮 2 代 GP，6 代 NSGA-II；其余参数保持原默认值。训练后验证选择和 SD、Rademacher 项保持不变。
3. 新版两组接收相同的无标签合法边界输入。旧版保留自身原始 API 和训练插值检查；此比较反映整个边界方案变化，不把它解释为单一代码行的因果效果。所有域约束来自显式输入规则：质心要求非负质量且总质量大于零；相对论公式要求光速大于零、速度绝对值小于光速。禁止根据真值的有限性筛掉坏预测。
4. 拟合子进程只打开训练/验证文件。全部拟合结束后才打开测试文件；真值、测试标签不参与结构排名、系数拟合或最终模型选择。显式边界点的坐标已知，其标签仍只在评分时使用。
5. 主指标为最终原始树在 IID、外推、精确边界、独立应力检查四组数据上的 NRMSE 均小于 `1e-6`。任何中间运算非有限都判为非法；不以 SymPy 约分结果替代原树。次指标为任一保存的 Pareto 候选通过相同门槛、IID R² 大于 0.999、非法运行数、候选非法数、量纲违规数、时间和搜索工作量。
6. 三组均有相同唯一树上限，但新版额外执行特征预览和线性子问题，必须报告这两类计数；这不是等计算量比较。最多同时运行 3 个单线程拟合进程，单次硬超时 240 秒。错误和超时保留并计入总分母，恢复执行不会挑选性重试。
7. 软件门槛：新增边界与复杂结构回归测试通过、所有保存树的量纲和容量限制合法、源代码和数据哈希一致、评分可重复。科学目标：边界非法运行数降到零，严格数值恢复较旧版提高。若不满足，照实记录；有限点通过不等于连续域合法性证明。

复现命令（从仓库根目录运行；先安装 `.[dev]`）：

```bash
python examples/boundary_search_study.py prepare --out outputs/my_boundary_study
python examples/boundary_search_study.py run --out outputs/my_boundary_study
python examples/boundary_search_study.py score --out outputs/my_boundary_study
python examples/boundary_search_study.py verify --out outputs/my_boundary_study
```
