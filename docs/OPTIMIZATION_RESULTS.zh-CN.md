## 实现的优化

1. **常数拟合**：修复直接常数偏移引起的根号/对数/分母初值问题；无可行初值时做有限多尺度重启。对常数联合线性的公式直接求解，非线性公式保留有界最小二乘。GP 继承未改变部分的系数，并对少量精英追加精调。
2. **搜索效率**：交换律规范化缓存、无效变异有限重试、跨轮保留多规模精英；加入符合相同语法与量纲的多项起始结构。第一阶段最多使用 75% 的唯一树预算，给 NSGA-II 留出空间。
3. **策略学习**：RNN 同时学习算子/终端与合法子树量纲组合；GP 精英模仿仍与 on-policy 策略梯度分开。
4. **候选优选**：预筛选保留精度、规模和 Pareto 代表；SD 继续调整 NSGA-II 同层拥挤度。大档案第一前沿用二维排序扫描提取。
5. **Rademacher**：改为系数 Jacobian 所张成局部输出球上的经验估计，减少常规冗余参数化的影响。以 `sqrt(n)/rho` 归一化后参与混合复杂度，同时保存原始估计；它衡量局部独立输出方向，不是整个非线性结构类的泛化界。
6. **物理约束与日志**：混凝土强度、船体阻力设置已知非负约束；只用训练输入构造 64 个凸组合检查点。记录实际新结构、RNN 候选质量、拟合失败原因、各 GP 算子效率和当前公式。

21 节点组为 10 个神经轮次、每轮 3 代 GP、6 代 NSGA-II、4000 个唯一树上限；31/41 节点组为 24 个神经轮次、每轮 3 代 GP、12 代 NSGA-II、8000 个唯一树上限。所有组均采用两次常规系数初值、每次最多 40 次优化函数评价，另有最多 8 个精英、每次最多 160 次的精调。Rademacher 使用 64 组符号抽样。参数权重未按测试集调优。

## 候选模型与示例公式

每个模型 JSON 都包含最终选择的表达式、原始树、常数及单位、验证有效的 Pareto 候选列表、配置与完整轮次日志。下列固定展示主配置的 seed 0，不挑选最佳种子。公式已将训练缩放还原到原始输入/输出数值单位，系数仅为展示舍入；预测请加载 JSON 原始树。

**翼型噪声**：36 个保存的 Pareto 候选；选中模型 33 节点。

```text
-22.5635*chord + 0.00147493*frequency*(0.0893802 - 20.4215*thickness**0.5) + 0.0782931*velocity + 130.165 + 39.5386*thickness*(0.000132111*frequency - 0.314701)/chord
```

输入数值单位：frequency: Hz；angle: degree；chord: m；velocity: m/s；thickness: m。

**混凝土强度**：28 个保存的 Pareto 候选；选中模型 35 节点。

```text
0.138352*cement + 0.0329752*coarse + 0.0426155*fine + 0.0986337*fly_ash - 0.0923736*water - 3.74458 - 48.5464*exp(-0.003419249097303*slag) - 36.2193*exp(-0.04203764698619768*age)
```

输入数值单位：cement: kg/m^3；slag: kg/m^3；fly_ash: kg/m^3；water: kg/m^3；superplasticizer: kg/m^3；coarse: kg/m^3；fine: kg/m^3；age: day。

**船体阻力**：35 个保存的 Pareto 候选；选中模型 35 节点。

```text
2.03638e-5*froude*prismatic*exp(21.59257194837402*froude)/(1.01552 - 0.312494*length_beam) + 26.0361*prismatic*(0.0579101*froude*prismatic - 0.0278001*exp(0.002181595459489654*buoyancy))**2*exp(22.10837973012499*froude)
```

输入数值单位：buoyancy: dimensionless；prismatic: dimensionless；length_displacement: dimensionless；beam_draught: dimensionless；length_beam: dimensionless；froude: dimensionless。

## 使用保存的实测模型

实测模型 JSON 接收的是实验中经过 SI 换算和训练缩放的输入。新样本必须使用对应 `splits` 文件中已保存的因子，输出再乘回原始单位；不要对新样本重新估计缩放因子。以下配方仅为推理用法示例，不是新增验证数据。

```python
import json
from pathlib import Path
import numpy as np
from dimensr import DimenSRRegressor
root = Path("results/optimization_v2")
model = DimenSRRegressor.load(root / "models/concrete_0_optimized_41.json")
pre = json.loads((root / "splits/concrete_0.json").read_text(encoding="utf-8"))["preprocessing"]
# cement, slag, fly_ash, water, superplasticizer, coarse, fine (kg/m³), age (day)
X_native = np.array([[350., 100., 0., 180., 6., 1000., 800., 28.]])
strength_MPa = model.predict(X_native * np.array(pre["x_native_to_model"])) * pre["y_model_to_native"]
print(strength_MPa)
```
